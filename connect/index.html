好啦体检 · 接入导引

两步：把 MCP 服务接给你的 AI 客户端，再把 Skill 装上。全程不需要改代码。

1接 MCP 服务

服务地址（只有一个，两个 Skill 共用）：

https://ai.ihaola.com.cn/api/mcp/haola-pe

Cursor 一键

点下面按钮，Cursor 会弹窗让你确认添加。

在 Cursor 中添加

VS Code 一键

需要 VS Code 1.102 或更新版本。

在 VS Code 中安装

Claude Code 一行命令

在终端里执行，然后新开一个会话。

claude mcp add --transport http haola-pe https://ai.ihaola.com.cn/api/mcp/haola-pe

WorkBuddy 一句话

在对话里直接发这句话，客户端会自己添加服务并弹出授权，不用改配置文件。

帮我连接 MCP：https://ai.ihaola.com.cn/api/mcp/haola-pe

没反应再走手动：编辑 %USERPROFILE%\.workbuddy\mcp.json，保存后在「连接器管理」里点一次信任，再新开会话。

其他客户端

任何支持远程 MCP（Streamable HTTP）的客户端都行。先试一句话：在对话里发「帮我连接 MCP：https://ai.ihaola.com.cn/api/mcp/haola-pe」，很多客户端会自己加好；没反应再手写下面这段。

{
  "mcpServers": {
    "haola-pe": {
      "type": "http",
      "url": "https://ai.ihaola.com.cn/api/mcp/haola-pe"
    }
  }
}

2装 Skill（给 AI 读的说明书）

装完 Skill，AI 才知道什么时候调哪个工具、按什么顺序出方案。两个场景各装一个，按需选。

场景Slug
个人体检、方案推荐、预约、订单、报告personal-checkup-booking
企业团检、人均预算分档报价、合同发票corporate-checkup-quote

个人版

clawhub install personal-checkup-booking

企业版

clawhub install corporate-checkup-quote
注意：不要用 @ryanbihai/personal-checkup-booking 这种写法。 ClawHub 详情页上给出的安装命令带了 @作者/ 前缀，但 clawhub 和 openclaw 两个 CLI 都不接受，会直接报 Invalid skill slug。 只写 slug 本身即可。

WorkBuddy 用户

WorkBuddy 读的是自己的技能目录，安装时指定 --workdir 就能直接装对位置，不用手动拷贝：

clawhub --workdir "$env:USERPROFILE\.workbuddy" install personal-checkup-booking --force

3装完之后

能力要登录吗怎么发生
查门店、查品牌覆盖、体检 FAQ、领域知识不要直接问，AI 直接调
个人体检方案推荐、预约、改期、取消、订单、报告要客户端弹出授权，点一次即可，之后 AI 接着算
企业团检方案与报价不要直接问，按人均预算出多档
我们不会向你要验证码、密码或银行卡信息。 登录只发生在客户端弹出的授权页面里。如果授权页显示「resource 无效」，说明这次没带授权上下文， 让 AI 重新发起一次即可，不用重填手机号。
